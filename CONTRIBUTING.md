# Contributing to Data Center Operations Lab

This independent educational project uses **fictional** data only. Contributions to calculations, accessibility, scenarios and documentation are welcome.

1. Open an issue with reproduction steps or a focused enhancement proposal.
2. Fork the repository, develop a small change, and test the app in a modern browser.
3. Submit a pull request referring to the issue and describing before/after behavior.
4. Include synthetic data only. Never share real facility layouts, access systems, credentials, network details, telemetry or other security-sensitive operational information.

Priority areas: KPI validation, reliability metrics, incident triage usability, energy and capacity planning methodology, mobile accessibility and CSV reporting.
